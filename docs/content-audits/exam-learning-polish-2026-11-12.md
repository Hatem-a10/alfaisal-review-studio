# Exam and learning polish — v1.46

- Examplify's mock title derives CVP/MOL/mixed course from the selected questions. A scope label such as `CVP · Accurate` no longer falls through to MOL. Existing previous-paper titles and the signed-in user's profile name are retained.
- Accurate generation reserves 10–16 actual question-image items before filling text questions, while respecting the exact user category allocations and all mandatory green repeats. Explanation-only figures do not count. Missing image capacity is an explicit error, never a silent image-free exam. The source filter now includes the existing `Image interpretation` questions; 28 existing CVP image questions were found with four individually explained choices. No new medical facts, decorative image fillers or publisher media were introduced.
- The two overlapping Learning tabs are merged into Practice & recall. Topic choices and counts use the same canonical core groups as the concept cards, retaining all topics and excluding optional duplicate versions. Whole-lecture practice is available. When late content arrives, an unfinished batch preserves existing answers/order by question ID while adding the newly available core questions.
- Existing authored matching and fill-in-the-blank exercises are retained inside a compact disclosure. Every topic also has an ungraded self-explanation prompt and revealable checklist drawn from its actual teaching/takeaways. Opening a checklist does not award mastery. Direct topic-practice links and Next topic intentionally scroll to the new set heading.
- Practice presentation is deferred into learning-practice.mjs/CSS rather than increasing startup payload. Existing saved study records and question identifiers remain intact; topic practice records under the open lesson.
- Mobile pager limits are calculated from the last visible navigation button rather than trailing scrollable space. Paging clamps both ends, reacts to tab/layout/visibility changes, respects reduced motion and moves focus without scrolling the page. No second mobile navigation strip is added.
- Profile appearance controls are positioned at the popup's top-right. Their former spacer row is removed and form spacing tightened. Reset/cancel and saved appearance behavior are preserved.

Verification: 18 focused tests cover real-bank image selection, category/green-repeat integrity, titles, canonical practice grouping, ungraded recall, profile controls and pager limits with trailing blank space. Fourteen isolated browser checks cover generated Examplify titles/images/attachments, practice topic and whole-lecture counts, populated recall, paging edges on six routes, the compact top-right setup controls, and bottom-positioned practice results scrolling into view. The production build passed the unchanged startup budget; screenshots and reports are under .sites-runtime/v146-smoke.
