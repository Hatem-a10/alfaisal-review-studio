# REN 123 instructor practice imports

Anzhelika’s Practice Questions lives under Practice Home → Previous Exams & TBLs → REN 123 → 19th Batch → Other. The six Moodle activities (635612, 635615, 635616, 636164, 636142, 635618) exposed 105 entries. Three were identical repeats within their respective activities. The combined set has 102 questions with source-confirmed keys and 18 distinct image assets. Two questions have figure-only prompts. Explanation figures appear after submission.

Keep the question text, source exports and figure bytes in private storage. Keep only the asset paths, byte counts and SHA-256 values in Git. Do not save temporary question-bank access URLs in the repository.

For later releases, retrieve new instructor activities through authorized access and record the displayed stem, choices in display order, source-revealed key, explanation, and every visual. The import expects an array of activity objects with `id`, `label` and `rows`. Each row contains `question`, `options`, `acceptedAnswers` (zero-based), `explanation` and `images`. Each visual uses `url`, `alt` and `region` (`question` or `explanation`). Store the validated image bytes locally with the SHA-256 of the image URL as the file basename and the real image format as its extension. Review new source formats before importing them.

Run `scripts/append-renal-practice-questions.mjs` with the current private Renal assessments pack, the captured activities, the local image directory and a new private output directory. Verify the base pack against the current manifest first. The script preserves existing question IDs, option order and keys. It accepts new questions and flags a changed key for editorial review. Merge the generated asset records into `lib/renal-assessment-assets.json` without the local file paths and update the Renal assessment request version. Upload and read back each new object in staging before testing. Use the reviewed production asset transfer and release process for live deployment.
