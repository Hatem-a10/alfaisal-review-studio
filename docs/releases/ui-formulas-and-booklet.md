# Booklet, mobile schedule and formula practice

- Wrong booklet answers remain in Unanswered and in the new Wrong filter. Feedback pins the checked question until Next; Next reinserts a miss at a random later queue position. Wrong items reopen as answerable retries. Existing correctness/history entries are retained.
- Accurate mode no longer enforces historical category floors/ceilings or the 76–143 size interval. Approximate category proportions guide selection only; source controls, green families, duplicate avoidance and 10–16 actual image questions remain. Practice size 20–200 supports those image constraints.
- Consolidated Question sources disclosure replaces the redundant source selector; Accurate, Examplify and Cheat Mode share a single row. CVP is first/default for fresh mock configuration.
- Navigation initialization is ordered, followed by a canonical desktop/mobile sidebar order. Quick search retains its header position and follows the appearance/date tile's open state.
- iPhone-width Schedule defaults to one day with weekday selection and optional Full week. Assigned timetable doctor names appear below lecture codes. Existing official periods/group bindings and completed reviews are untouched. Light timetable blocks have filled, higher-contrast colors.
- Examplify appearance changes are scoped exclusively to Light Mode: selected-only navigator/color rings, visible eye/check icons, toolkit text/header contrast, marker shape/swatches and Next color. Dark Mode rendering remains unchanged.
- Welcome flow now uses intrinsic height, neutral surfaces and live semantic accent colors. Appearance controls are outside hidden steps; color input is constrained and never autofocuses. English time is below English days; selected lab group joins class/section in the profile label. Sync/Settings share accent styling.
- Formulas is a Practice & MCQs tab with 53 curriculum-linked calculations, 159 repeatable numerical exercises, inversions and multi-step workings. Responses are stored per student in existing options without awarding lesson mastery. See docs/content-audits/cvp-formula-practice.json for scope, exclusions and source clarifications. Original formula-sheet errors are not silently copied into teaching. New numerical exercises are authored practice, not lecturer exam questions.

Validation: build; 15 focused isolated-browser checks with synthetic data, including formula answers, booklet feedback/queues, flexible Accurate generation (20 and 100 questions), mobile day timetable/lecturer visibility, navigation order, aligned mode controls, Light selection rings and compact onboarding/English field order. Screenshots inspected at phone width. Browser checks use Chromium emulation, not a physical iPhone or Safari engine. No full regression suite or subagents used. Existing D1/R2 bindings, project, accounts and saved progress preserved.
