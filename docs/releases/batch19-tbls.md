# Batch 19 TBL import and catalog organization

Five supplied papers, 84 source items: TBL1 16, TBL2 19, TBL3 15, TBL4 18, TBL5 16. Total 58 MCQs and 26 written-answer parts. Five source figures are attached to the relevant ECG, radiograph and graph questions. TBL4 was image-only; Luna transcribed all five pages. Its canceled MCQ and MCQ without an explicit printed key are retained ungraded and excluded from generated MCQ pools. TBL5 Q12 preserves the source's explicitly accepted B/C alternatives in scoring and shuffled options. Printed wording/keys are retained; combination tables are expanded into readable choices, without adding options or inferring absent keys.

New sets use stable cvp19-tbl-1 through cvp19-tbl-5 identifiers. Question provenance includes original PDF SHA-256 and page references. Originals are kept in existing private R2 storage. Content-addressed objects are verified before bundled media copies are removed.

Unlabelled catalog entries are hidden; their questions, sources and saved attempts are retained. Shams collections route to Batch19 / Other. Corrected booklet collections route to both Topics and Batch19 using their original set/question IDs. Previous TBLs in verified generation is restricted to supplied Batch19 papers; older/unlabelled TBL membership is not admitted by that toggle.

Focused validation: 84 unique item IDs and original MCQ choice lengths; four isolated browser checks for paper counts, catalog routing, source restriction (56 keyed, non-canceled MCQs) and explicit alternate-key grading after shuffling. Standard build. No broad regression suite; one Luna subagent used only for image transcription. Existing user progress, answer snapshots, Site project/audience and D1/R2 bindings retained.
